# Data Analyst Internship – Task 2  
## Excel Analysis using Pivot Tables

## 📌 Objective
The objective of this task is to analyze sales data using Excel Pivot Tables, summarize key business metrics, and derive meaningful insights to support decision-making.

---

## 📂 Dataset Used
- Superstore Sales Dataset

---

## 🛠 Tools Used
- Microsoft Excel

---

## 📊 Tasks Performed
- Cleaned and prepared the dataset for analysis
- Converted raw data into Excel Table format
- Created Pivot Tables to analyze:
  - Total Sales by Category
  - Sales by Region and Segment
  - Profit Margin by Category and Region
- Added slicers for interactive filtering
- Created pivot charts for visual comparison
- Calculated Profit Margin using a derived column
- Summarized key business insights
- Exported final report as Excel and PDF

---

## 📁 Files in This Repository
- `Pivot_Report.xlsx` – Excel file containing pivot tables and charts  
- `Pivot_Report.pdf` – Exported PDF report  
- `insight.txt` – Summary of key insights derived from analysis  
- `Raw_Data.xlsx` – Original dataset used for analysis  
- `README.md` – Task description and explanation  

---

## 📌 Key Learnings
- Understanding and using Pivot Tables for data summarization
- Analyzing sales and profitability across categories and regions
- Creating interactive dashboards using slicers
- Converting analysis results into business insights

---

## ✅ Conclusion
This task helped in gaining hands-on experience with Excel Pivot Tables, data aggregation, and analytical storytelling, which are essential skills for a Data Analyst role.
